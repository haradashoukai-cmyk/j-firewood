# 日本焚火研究所 ホームページ

川崎市多摩区で薪を販売する「日本焚火研究所」のホームページです。
GitHub Pages で公開し、ドメイン j-firewood.jp（エックスサーバーで取得）をここに向けます。

## ファイルの説明

| ファイル | 中身 |
|---|---|
| `index.html` | トップページ（薪のある生活・薪の販売・アクセス・ブログの新着・お問合せ） |
| `products.html` | 薪の販売（商品一覧と購入の流れ） |
| `blog/index.html` | ブログの一覧 |
| `blog/2025-08-09.html` | ブログの記事（1記事 1ファイル。ファイル名は日付） |
| `contact.html` | お問合せフォーム（送信内容は FormSubmit 経由で kanri@haradakanri.jp へ届く） |
| `thanks.html` | フォーム送信後に表示するページ |
| `css/style.css` | 色・文字・配置の設定（全ページ共通） |
| `images/` | 写真を置く場所 |

## 更新のしかた

Claude デスクトップアプリでこのフォルダを開き、「ブログに○○の記事を足して」「一束の値段を900円にして」のように頼むと、
Claude がファイルを直して GitHub に送ります。送ってから数分で公開されます。
